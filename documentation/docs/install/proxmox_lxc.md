# Proxmox LXC

AdventureLog can run in a Proxmox LXC container, set up by a community script from the Proxmox VE Helper-Scripts project.

## Install

Follow the [AdventureLog script page](https://community-scripts.github.io/ProxmoxVE/scripts?id=adventurelog). It shows the command to run on your Proxmox host and the resources the container gets.

The script is maintained by the Proxmox VE Helper-Scripts community, not by the AdventureLog project. For problems with the script itself, use their issue tracker.

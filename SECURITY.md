# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in AdventureLog, please report it privately through one of these channels:

1. **GitHub private vulnerability reporting** — open a private advisory from the [Security advisories](https://github.com/seanmorley15/AdventureLog/security/advisories/new) page (preferred when available)
2. **Email:** `contact@adventurelog.app`

Do **not** open a public GitHub issue for security reports.

A useful report includes:

- A clear description of the vulnerability
- Steps to reproduce it
- The affected version or Docker image tag, if known
- The potential impact
- Any suggested fix, if you have one

We will acknowledge your report as soon as we can and work with you on a fix. Please give us reasonable time to release a patch before any public disclosure.

Thank you for helping keep AdventureLog and its users safe.
